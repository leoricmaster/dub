# PRD — dub

> 给优秀英文纪录片加中文 AI 配音，让低龄孩子能看懂。本地 CLI，个人自用。
>
> v0.1（P1 MVP 已落地）｜ 2026-08-10

## 定位

国内可达、低成本、可缓存、可断点续跑的中文配音命令行工具。不拼音色克隆与多语言规模化，只把「英文纪录片 → 自然中文配音」一件事做扎实。

## 用户与场景

家长：孩子看不懂没有中文配音的优秀纪录片（BBC 自然、科普等）。用 dub 生成一条中文配音轨写回 mkv，孩子就能看。

## 目标

- **翻译准确、地道**，孩子听得懂。
- **配音自然**，语速贴合画面，不抢不拖。
- **低成本可迭代**：~¥10/集，改配置只重跑受影响阶段。
- **中长期单人可维护**：分层清晰、有测试。

## 非目标

- ❌ SaaS / 多用户 / Web UI / 账号计费
- ❌ 音色克隆、表演级配音
- ❌ 画面/字幕烧录、唇形同步（只加音频轨）
- ❌ 大规模批量分发

## 功能需求

`extract → transcribe → translate → tts → mix → mux`，中文作为附加轨写入 mkv，默认不抢占原轨。横切：hash 缓存与续跑；CLI（zh / translate / voices）；音色预设。

## 非功能

| 维度 | 指标 |
|---|---|
| 成本 | ≤ ¥15/集（50 分钟） |
| 可维护 | 核心纯函数有单测，CI 绿 |
| 鲁棒 | API 失败可重试、不污染缓存 |
| 隐私 | 音频只进用户自有云账号 |

## 法务

个人自用。仅处理自有或有权观看的内容。

## 路线图

- **P1（已落地）**：六阶段串接、缓存续跑、整体衰减混音。
- **P1.5（核心质量）**：翻译地道化、时长对齐、音色固化、补测试。
- **P2（增强）**：人工校对回路、术语表、人声/BGM 分离。
